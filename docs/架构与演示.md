# Incident Agent 架构与演示

## 1. 一次正常运行

```text
浏览器提交 title/content/knowledge_base_id
        │
        ▼
Agent API 校验 JWT 和请求体
        │
        ▼
创建 agent_runs，初始化 AgentState
        │
        ▼
agent 节点请求 DeepSeek
        │
        ├── analyze_log
        ├── search_knowledge ──► DevAtlas /search
        └── get_service_status
        │
        ▼
ToolNode 执行工具，observe 整理 ToolMessage
        │
        ├── 有失败 → degrade → 保存 degraded
        └── 全部成功 → 再次请求模型
                              │
                              └── 无 tool_calls → report
                                                   │
                                                   ├── JSON 解析
                                                   ├── IncidentReport 校验
                                                   └── 保存 completed
```

## 2. State 中的三类数据

| 字段 | 用途 |
| --- | --- |
| `messages` | 给模型继续推理的 LangChain 消息协议 |
| `observations` | 工具结果整理后的业务事实 |
| `steps` | 节点、工具和错误的审计轨迹 |

一次运行中，`iteration` 统计模型请求轮数，不统计工具数量。一轮模型返回三个 `tool_calls` 仍然只增加一次 `iteration`。

## 3. 正常演示

前置条件：

- DevAtlas 后端运行在 `8000`；
- Agent 后端运行在 `8001`；
- Web 运行在 `5174`；
- DevAtlas 用户拥有知识库 `3`；
- 知识库文档版本为 `indexed`；
- `.env` 已配置 DeepSeek Key。

步骤：

1. 打开 `http://127.0.0.1:5174`；
2. 使用 DevAtlas 账号登录；
3. 知识库 ID 填 `3`；
4. 输入“订单服务返回 502”和 MySQL 超时日志；
5. 点击开始分析；
6. 查看工具轨迹、来源文件、chunk、可能原因和排查步骤；
7. 打开运行历史，确认可以回看这次 `run_id`。

## 4. 失败演示

将日志改为要求查询不存在的 `gateway` 服务，预期：

```text
get_service_status → UNKNOWN_SERVICE
status → degraded
report → null
observations 保留已获得的工具结果
```

也可以暂时停止 DevAtlas，验证检索工具返回 `RAG_NETWORK_ERROR` 或 `RAG_UNAVAILABLE` 后安全降级。

## 5. 设计边界

- Agent 只提供排查建议，不执行 Shell、重启、改配置和生产修复；
- Pydantic 校验只能证明结构正确，不能证明模型陈述的事实真实；
- 真实引用必须来自 DevAtlas metadata；
- 模型输出不是固定的工具数量，测试使用 FakeModel 保证自动化稳定；
- Web 当前是同步 JSON MVP，SSE 流式展示属于后续增强。

## 6. 面试讲法

DevAtlas 是通用的版本化研发知识库，负责文档处理、权限和检索；Incident Agent 是上层的故障分析应用，通过工具接口复用 DevAtlas 的纯检索能力。Agent 使用 LangGraph 编排模型决策、日志分析、知识检索和服务状态查询，把消息上下文、业务观察和执行轨迹分开保存，并用条件边处理继续调用、报告生成、工具失败和最大轮数。最终报告由独立节点生成 JSON，再用 Pydantic 校验，引用保留 document、version 和 chunk 信息。
